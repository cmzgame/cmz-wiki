The game nods now and then to real things outside its own world: a song, a book, a film. Michael ruled on 2026-10-18 that every such reference is kept in one place, so that anyone who needs to see them all at once, a lawyer before the game's launch among them, finds them on one page. The game keeps them as data, and this table is generated from it, so it is always the game's own list.

{{references-table}}

Each entry names what in the game carries the reference (an item, so far), its name in the game, the work it refers to, what the nod is, and when and by whom it was made explicit.
